# initiative-prioritization

Skill de **Strategic Opportunity Radar** (Dirección).

## When to use
El usuario pide priorizar iniciativas del roadmap o comparar alternativas.

## Instructions
1. Listar iniciativas desde el roadmap.
2. Puntuar con criterios explícitos y pesos acordados.
3. Analizar sensibilidad a cambios de pesos.
4. Recomendar top 3 con riesgos.

## Output
Ranking con puntaje por criterio y análisis de sensibilidad
