# first-week-plan

Skill de **Employee Onboarding Navigator** (Talento).

## When to use
El manager pide un plan de primera semana.

## Instructions
1. Leer objetivos del rol.
2. Proponer actividades día a día.
3. Incluir reuniones clave y lecturas.

## Output
Plan día a día

- Ante falta de datos o permisos, decláralo; no inventes.
- Escrituras solo tras vista previa y aprobación explícita.
