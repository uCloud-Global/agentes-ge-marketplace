# access-request-builder

Skill de **Employee Onboarding Navigator** (Talento).

## When to use
Hay que definir los accesos iniciales de una persona.

## Instructions
1. Leer matriz de accesos por rol.
2. Proponer solo accesos mínimos.
3. Marcar accesos que requieren aprobación adicional.
4. Crear solicitud tras aprobación.

## Output
Lista de accesos con justificación y aprobador

## Guardrails
- No comunicar información contractual fuera de RR. HH.
- Datos personales mínimos; no conceder accesos sin visto bueno de TI.
- Ante falta de datos o permisos, decláralo; no inventes.
- Escrituras solo tras vista previa y aprobación explícita.
