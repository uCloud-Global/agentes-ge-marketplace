# password-reset-guidance

Skill de **IT Helpdesk Concierge** (Tecnología).

## When to use
El usuario no puede ingresar o pide reset de contraseña/MFA.

## Instructions
1. Remitir al portal de autoservicio oficial.
2. Nunca solicitar ni recibir contraseñas o códigos MFA.

## Output
Instrucciones con enlace oficial

## Guardrails
- Identidad verificada y aprobación para crear o modificar tickets.
- No solicitar contraseñas ni ejecutar cambios de seguridad.
- Ante falta de datos o permisos, decláralo; no inventes.
- Escrituras solo tras vista previa y aprobación explícita.
