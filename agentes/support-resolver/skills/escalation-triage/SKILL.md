# escalation-triage

Skill de **Customer Support Resolver** (Clientes).

## When to use
Caso de alto riesgo: fraude, legal, cliente VIP, amenaza de churn o reembolso fuera de política.

## Instructions
1. Detectar criterio de escalamiento.
2. Resumir caso en 5 líneas.
3. Asignar nivel y responsable según matriz.
4. No responder al cliente con compromisos.

## Output
Nota de escalamiento con criterio y responsable

## Guardrails
- Validar identidad del cliente y aprobar actualizaciones/envíos.
- Escalar incidentes de alto riesgo, no prometer reembolsos no aprobados.
- Ante falta de datos o permisos, decláralo; no inventes.
- Escrituras solo tras vista previa y aprobación explícita.
